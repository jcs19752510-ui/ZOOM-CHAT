## 실행
```bash
npm run test:e2e                          # 웹 빌드 후 전체
npx playwright test -g "IT-03"            # 하나만
```
환경: Chromium 가짜 카메라·마이크(`--use-fake-device-for-media-stream`), 서버를 테스트 프로세스 안에서 띄움(`e2e/fixtures.ts`), STUN 없이 루프백 직접 연결. 모든 시나리오는 실제 브라우저·실제 서버·실제 WebRTC 연결로 동작한다.
