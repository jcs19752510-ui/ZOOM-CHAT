## 상태
승인(구현됨)

## 배경
영상·채팅을 서버에 저장하지 않는 정책이고 서버는 1대다. 영속 저장소는 운영 복잡도를 늘린다.

## 결정
방·참가자 상태를 `Map`으로 메모리에 둔다. 서버 재시작 시 방이 사라지는 것을 허용하고, 클라이언트에는 이유와 새 방 만들기를 안내한다(FR-21).

## 결과·트레이드오프
- 장점: 단순, 데이터 보관 없음(POL-09).
- 단점: 재시작·장애 시 모든 회의 종료(RISK-07), 수평 확장 불가(비목표). 배포·재시작 시간 최소화와 안내가 필요.
