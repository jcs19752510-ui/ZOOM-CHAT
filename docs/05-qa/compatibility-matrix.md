## 알려진 제약과 대응(코드 반영, 일부는 미검증)
| 항목 | 내용 | 상태 |
|---|---|---|
| iOS Safari 자동재생·인라인 재생 | `<video playsInline autoPlay>`, 첫 사용자 동작(입장 버튼) 이후 재생 | 코드 반영, **실기기 미검증** |
| 모바일 화면공유 | 지원하지 않음. 버튼 비활성+안내(`supportsScreenShare`) | 로직 구현, 모바일 UA 시험은 단위로 미검증 |
| 출력 장치 선택(`setSinkId`) | 지원하는 브라우저에서만 표시 | 구현, 브라우저별 **미확인**(A-08, U-05) |
| iOS 백그라운드 | 미디어 중단 가능 → 복귀 시 재연결·ICE 재시작 | 구현, **미검증** |
| 인앱 브라우저 | 미디어 권한 제한 가능 → 지원 불가 안내 화면 | 구현(IT-18은 WebRTC 없음 가정), 실제 인앱은 **미검증** |
| 보안 컨텍스트 | HTTPS 또는 localhost가 아니면 카메라 불가 → 지원 불가 안내 | 구현 |

수동 시험 절차: 대상 기기에서 호스트(데스크톱 Chrome)가 방을 만들고, 대상 기기가 링크로 입장 → 영상·소리 양방향 확인 → 채팅 → 마이크/카메라 토글 → 네트워크 전환(Wi-Fi↔LTE)으로 재연결 확인 → 결과를 `uat.md`에 기록.
