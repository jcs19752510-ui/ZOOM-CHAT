## 1. 처리하는 데이터
| 데이터 | 어디서 | 서버 저장 | 보관 |
|---|---|---|---|
| 영상·음성·화면 | 브라우저 간 P2P(직접 연결 실패 시 TURN이 암호화된 패킷을 중계) | **저장 안 함**(서버는 복호화 불가) | 없음 |
| 채팅 본문 | 서버가 같은 방에 릴레이 | **저장·로그 안 함** | 없음(방 종료 시 소멸) |
| 닉네임 | 방 상태(메모리) | 방이 있는 동안만 | 방 삭제 시 소멸. 로그에 남기지 않음 |
| IP 주소 | 접속 시 서버가 인지 | 원문 저장 안 함. 강퇴된 경우에만 **단방향 해시**를 방 메모리에 보관 | 방 삭제 시 소멸 |
| SDP·ICE(IP 포함) | 시그널링 릴레이 | 저장·로그 안 함 | 없음 |
| 방 비밀번호 | 방 생성 시 | **bcrypt 해시**만 메모리 | 방 삭제 시 소멸 |
| TURN 사용 | coturn이 연결 정보를 가질 수 있음 | coturn 로그 설정에 따름(`simple-log`, 사용자 정보 최소) | 운영 정책으로 정함 |
| 로컬 저장 | 브라우저 `localStorage`: 마지막 닉네임, `sessionStorage`: 방 생성자 클레임(탭 한정) | 서버 아님 | 사용자가 삭제 가능 |

## 2. 데이터 흐름
```
브라우저 A ⇄ (WSS) ⇄ 서버(메모리) ⇄ (WSS) ⇄ 브라우저 B      ← 방 상태, 채팅, 신호
브라우저 A ⇄ (SRTP, 직접) ⇄ 브라우저 B                         ← 영상·음성·화면
브라우저 A ⇄ (TURN, 암호화 패킷) ⇄ coturn ⇄ 브라우저 B         ← 직접 연결 실패 시
브라우저 → STUN 서버(기본: 공개 STUN)                           ← 공인 주소 확인(제3자)
```

## 3. 제3자
- STUN: 기본 설정이 공개 STUN 서버(`stun.l.google.com:19302`)다. 클라이언트의 공인 IP가 이 서버에 전달된다. 원치 않으면 `STUN_URLS`를 비우거나 자체 STUN으로 바꾼다(IT-21은 STUN 없이 동작).
- TURN: 운영자가 직접 운영하는 coturn. 외부 서비스를 쓰면 그 서비스에 트래픽이 지난다.
- 외부 폰트·분석 도구·광고: **없음**(웹은 시스템 폰트, 외부 요청 없음).

## 4. 이용자 고지
- 대기실: "영상 통화를 연결하는 과정에서 다른 참가자에게 내 네트워크 정보(IP 주소 등)가 보일 수 있습니다." (UX-09)
- 처리방침·이용약관은 `legal-drafts/`의 **초안**이며 법률 검토 전이다.

## 5. 이용자 권리·삭제
계정·프로필이 없고 서버 저장이 없어 별도 삭제 요청 대상이 거의 없다. 방은 종료되면 사라진다. 로그에는 개인정보를 남기지 않으므로 로그 삭제 요청 대상이 없다(운영자 로그 정책 확인).

## 6. 확인이 필요한 것 (사용자)
U-04 적용 법령과 요건(개인정보 처리 여부 판단, 국외 이전 해당 여부, 고지·동의 방식), U-03 운영자 연락처, 공개 STUN 사용에 대한 방침.
