## 1. 비전과 문제 정의
- **비전**: 링크 하나로, 설치와 가입 없이 6명 이하 모임이 바로 얼굴을 보고 이야기한다.
- **문제**: 소규모 모임(스터디, 가족, 소모임)은 화상회의 앱 설치·로그인·시간제한 때문에 시작 단계에서 이탈한다. 비전문가(특히 모바일 사용자)는 카메라·마이크 권한 설정에서 막힌다. (이 문제 서술은 기획 가설이며 실제 이용자 조사는 하지 않았다: **미확인**)
- **해결**: 브라우저 링크 입장, 대기실에서 장치 확인, 막혔을 때 원인과 해결 방법을 한국어로 안내.

## 2. 타깃과 가치 제안
| 구분 | 내용 |

| 타깃 | 6명 이하 소규모 모임의 호스트와 참가자(비전문가 포함), 서비스를 혼자 운영하는 개발자 |
| 가치 | ① 설치·가입 없음 ② 링크 클릭 후 3번 이내 조작으로 입장 ③ 서버에 영상·채팅을 저장하지 않음 ④ 문제 발생 시 해결 방법까지 안내 |
| 비가치(약속하지 않음) | 대규모 웨비나, 녹화, 계정 기반 일정 관리 |

## 4. 차별점 (가설)
1. 한국어 중심의 **원인+해결 방법** 오류 안내 (UX-03).
2. 대기실에서 카메라·마이크·네트워크 정보 고지까지 한 화면에서 처리 (FR-04, UX-09).
3. 서버 비저장 원칙을 정책으로 명시 (POL-09).
4. 소규모 전용으로 구조를 단순화해 1인이 운영 가능 (NFR-11).

## 5. 비용 구조 가설
수치는 모두 **미확인**이며 배포 후보 비교(0-C `infra-deploy.md`)에서 확정한다.
- 고정비: 서버 1대(앱 + coturn 동거 가능), 도메인, TLS 인증서(무료 발급 가능 여부는 배포 대상에 따라 확인).
- 변동비: **TURN 중계 트래픽**이 핵심 변수. 직접 연결(P2P)이 성립하면 미디어는 서버를 지나지 않는다. TURN 경유 비율은 **미확인**이며 KPI-05로 관측한다.
- 계산 틀(가정): mesh에서 참가자 1명의 업로드 = (인원 − 1) × 영상 비트레이트. 6명이면 5개 스트림을 올린다. 비트레이트는 0-C에서 상한을 정한다.
