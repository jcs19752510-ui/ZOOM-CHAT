> **이 문서의 용도** — 누가: MeetLite를 처음 쓰는 이용자(호스트·참가자, 컴퓨터나 화상회의에 익숙하지 않은 분 포함) / 언제: 처음 회의를 만들거나 들어갈 때, 그리고 화면이 이상하거나 오류 문구가 나올 때 / 무엇을: 따라 하면 입장해서 서로 얼굴이 보이는 데까지 가는 방법과, 막혔을 때 무엇을 눌러야 하는지를 정한다.

## 1. MeetLite가 뭐예요?
**설치도 가입도 없이, 링크 하나로 들어가는 화상회의**입니다. 한 방에 **최대 6명**까지 함께할 수 있어요. 회의 내용(영상·소리·채팅)은 서버에 저장되지 않고, 방이 끝나면 사라집니다. 녹화 기능은 없습니다.

## 2. 시작하기 전에 (준비물)
| 필요한 것 | 설명 |
|---|---|
| 인터넷이 되는 기기 | 컴퓨터(가장 권장), 휴대폰, 태블릿 |
| 최신 브라우저 | **Chrome, Edge, Firefox, Safari** 최신 버전. 인터넷 주소창이 있는 그 프로그램입니다 |
| 카메라·마이크 | 없어도 들어갈 수 있어요(보고 듣고 채팅은 가능) |
| 주소가 `https://`로 시작하는지 | 보안 연결이 아니면 카메라가 동작하지 않습니다 |

## 3. 회의 만들기 (호스트)
**호스트**는 회의를 만든 사람입니다.
1. 첫 화면 「링크 하나로 바로 시작하세요」에서 **닉네임**(회의에서 보일 이름)을 씁니다. 1~20자, 한글·영문·숫자·공백·`_` `-` `.`만 쓸 수 있어요.
2. (선택) **「비밀번호 설정 (선택)」**을 눌러 4~32자 비밀번호를 정합니다. 비밀번호는 링크에 들어가지 않으니 **참가자에게 따로 알려 주세요.**
3. **「새 회의 만들기」**를 누릅니다.
4. 「입장 전 확인」 화면이 나옵니다(§5). 카메라가 잘 나오는지 보고 **「회의 입장」**을 누릅니다. 이때 브라우저가 카메라·마이크를 써도 되는지 물으면 **「허용」**을 누르세요.
5. **「초대 링크 복사」**(회의 화면에서는 위쪽 「링크 복사」)를 누르면 링크가 복사됩니다. 카카오톡·문자·메일에 **붙여넣기**해서 보내세요. 복사가 안 되면 화면에 보이는 링크를 직접 선택해 복사하면 됩니다.

> **중요(호스트)**: 방을 만든 **그 탭(창)을 닫지 마세요.** 호스트는 그 탭에서 입장해야 호스트가 됩니다. 호스트가 아직 들어오지 않았다면 다른 사람은 「호스트를 기다리고 있습니다」 화면에서 기다립니다.

## 4. 회의 들어가기 (참가자)
1. 받은 링크를 누릅니다(설치·가입 필요 없음). 링크는 `…/r/` 뒤에 긴 글자가 붙은 모양입니다.
2. **닉네임**을 쓰고, 비밀번호 방이면 **방 비밀번호**를 씁니다(호스트가 알려 준 것).
3. 카메라·마이크 **「허용」** → **「회의 입장」**.

링크가 눌러지지 않거나 메모만 있다면: 첫 화면의 「초대 링크가 있나요?」 칸에 링크(또는 방 코드)를 **붙여넣고 「입장」**을 누르세요. 「올바른 회의 링크가 아닙니다」가 나오면 받은 링크를 그대로 다시 붙여넣어 주세요.

- 호스트가 아직 안 왔으면 「호스트를 기다리고 있습니다」가 보입니다. **이 화면을 닫지 마세요.** 호스트가 들어오면 자동으로 시작됩니다.
- 카카오톡 같은 앱 안에서 링크를 열면 카메라가 막힐 수 있어요. 안내가 나오면 링크를 복사해서 **Chrome이나 Safari**에서 여세요.

## 5. 입장 전 확인 화면
| 화면에 보이는 것 | 하는 일 |
|---|---|
| 「내 카메라 미리보기」 | 내 얼굴이 나오는지 확인 |
| 「마이크 입력 레벨」 | 말하면 막대가 움직여야 마이크가 되는 것 |
| 마이크·카메라·스피커 선택 | 장치가 여러 개일 때 원하는 것을 고름(스피커 선택은 일부 브라우저만) |
| 「장치 없이 입장」 | 카메라·마이크가 없거나 막혔을 때, 보고 듣기만 하고 들어감 |
| 안내 문구 | 영상 통화를 연결하는 과정에서 **다른 참가자에게 내 네트워크 정보(IP 주소 등)가 보일 수 있습니다.** 읽어 보세요 |

## 6. 회의 화면 사용법
아래쪽 버튼 줄(왼쪽부터 순서대로)입니다.
| 버튼 | 하는 일 |
|---|---|
| **마이크** | 눌러서 끄기/켜기. 꺼지면 빨간 표시가 나옵니다 |
| **카메라** | 눌러서 끄기/켜기 |
| 마이크·카메라 옆 **︿** (컴퓨터) / 위쪽 **톱니바퀴**(휴대폰) | 「장치 설정」: 마이크·카메라·스피커 바꾸기 |
| **화면공유** | 내 화면 보여 주기(**컴퓨터만**, §8) |
| **채팅** | 글로 대화하기(§7). 안 읽은 메시지는 숫자로 보입니다 |
| **참가자** | 누가 있는지 보기. 호스트는 여기서 도구를 씁니다(§9) |
| **나가기**(빨간 버튼) | 회의에서 나가기. 한 번 더 확인합니다. 같은 링크로 **다시 들어올 수 있어요** |

- 말하는 사람의 화면에 **테두리 강조**가 생깁니다. 사람이 1~6명이면 화면이 알맞게 나뉘고, 누가 화면공유를 하면 공유 화면이 크게, 사람들은 작게 보입니다.
- 상대방 이름 옆 표시: 「연결됨」, 「불안정」(네트워크가 안 좋음), 「재연결 중」, 「카메라 꺼짐」.
- 「아직 아무도 없어요」가 보이면 링크를 복사해 참가자를 초대하세요.
- 누가 들어오거나 나가면 짧은 알림이 뜹니다.

## 7. 채팅
1. **채팅** 버튼을 누르고, 아래 칸에 메시지를 쓴 뒤 **「보내기」**(최대 **500자**).
2. 대화는 **서버에 저장되지 않고 회의가 끝나면 사라집니다.** 늦게 들어온 사람은 그 전 대화를 볼 수 없습니다(저장하지 않기 때문입니다).
3. 인터넷 주소(`http://`, `https://`)는 눌러 열 수 있는 링크로 보입니다. **모르는 사람이 보낸 링크는 조심하세요.** 글자와 실제 주소가 다를 수 있습니다.
4. 「너무 빨리 보내고 있습니다」가 나오면 잠시 뒤에 보내세요. 「보낼 수 없는 내용입니다」는 눈에 보이는 글자를 넣어 다시 보내라는 뜻입니다.

## 8. 화면공유 (컴퓨터에서만)
1. **화면공유**를 누르면 브라우저가 무엇을 공유할지 묻습니다(전체 화면·창·탭). 하나를 골라 허용하세요.
2. 공유 중에는 버튼이 **「공유 중지」**로 바뀝니다. 끝내려면 누르세요.
3. **한 번에 한 명만** 공유할 수 있습니다. 다른 사람이 공유 중이면 「○○님이 이미 화면을 공유 중입니다」가 나옵니다. 그 사람이 끝낸 뒤에 시작하세요.
4. 「화면공유가 취소되었거나 권한이 없습니다」는 선택 창을 닫았다는 뜻이니 다시 눌러 보세요.
5. **휴대폰·태블릿 브라우저에서는 화면공유를 쓸 수 없습니다**(버튼이 눌리지 않고 「모바일 브라우저에서는 화면공유를 지원하지 않습니다」가 보입니다).

## 9. 호스트 도구
**참가자** 버튼을 열면 호스트에게만 보이는 도구가 있습니다(호스트가 아니면 쓸 수 없고, 누르면 「호스트만 할 수 있는 기능입니다」).
| 도구 | 하는 일 |
|---|---|
| **방 잠그기** / 방 잠금 해제 | 잠그면 **새로 들어오려는 사람**이 들어올 수 없습니다. 이미 있는 사람은 그대로입니다 |
| **전체 음소거** | 호스트를 뺀 모두의 마이크를 끕니다. **각자 다시 켤 수 있어요** |
| **내보내기** | 한 명을 내보냅니다. 한 번 더 확인합니다 |

**내보내기의 한계를 꼭 알아 두세요.** 내보낸 사람은 그 방에 다시 들어올 수 없습니다. 그런데 이 차단은 계정이 아니라 **인터넷 연결 정보**로 합니다.
- 같은 인터넷(같은 집·사무실 공유기)을 쓰는 **다른 사람이나 호스트 본인까지** 다시 들어갈 때 「회의에서 내보내졌습니다」가 나올 수 있습니다. 이럴 때는 **새 회의를 만들어** 옮기세요.
- 반대로 **휴대폰 데이터 같은 다른 인터넷으로 바꾸면** 다시 들어올 수 있습니다. 괴롭힘이 계속되면 **방 잠그기**를 쓰세요.

**호스트가 나가면**: 가장 먼저 들어온 참가자가 새 호스트가 됩니다(「이제 내가 호스트입니다」). **원래 호스트가 같은 링크로 다시 들어오면 일반 참가자**로 들어옵니다. **브라우저를 새로고침하거나 탭을 닫았다 열면 "새 참가자"로 다시 들어가는 것**이라 호스트 권한을 잃을 수 있어요. 호스트는 새로고침을 하지 마세요.

## 10. 연결이 끊겼을 때
- 「재연결 중」: 인터넷이 잠깐 끊긴 것입니다. **20초 안에 돌아오면 같은 자리에서 계속**됩니다(자동으로 다시 연결합니다). 기다려 주세요.
- 「연결이 오래 끊겨 회의에서 나갔습니다」: 너무 오래 끊겨 자리가 정리됐습니다. **「다시 입장」**을 누르세요.
- 「서비스가 재시작되어 회의가 종료되었습니다」: 서비스를 점검하는 중입니다. 방이 모두 사라집니다. **새 회의를 만들어** 다시 시작하세요.
- 「운영자가 이 회의를 종료했습니다」: 운영자가 이 회의를 닫았습니다. 같은 링크로는 다시 못 들어옵니다. 새 회의를 만들 수 있고, 이유가 궁금하면 화면 아래 「문의·신고」를 보세요.
- **휴대폰**: 화면을 끄거나 다른 앱으로 가면 통화가 멈출 수 있어요. 돌아오면 자동으로 다시 연결을 시도하고, 카메라·마이크가 멈췄다는 안내가 나오면 그 버튼을 다시 누르세요. 회의 중에는 브라우저를 켜 둔 채로 두세요.

## 11. 문제 해결 (FAQ)
| 화면에 보이는 말 / 문제 | 이렇게 해 보세요 |
|---|---|
| 「카메라·마이크를 사용할 수 없습니다」 — 권한이 차단됨 | 주소창 왼쪽 **자물쇠 아이콘** → 카메라·마이크 **허용** → **새로고침**. 급하면 「장치 없이 입장」 |
| 「연결된 카메라나 마이크를 찾지 못했습니다」 | 장치가 꽂혀 있는지 확인. 장치 없이도 입장할 수 있어요 |
| 「다른 앱이 카메라나 마이크를 사용 중입니다」 | 다른 화상회의·카메라 앱을 닫고 **「다시 확인」** |
| 「이 브라우저에서는 사용할 수 없습니다」 | 최신 Chrome/Edge/Firefox/Safari로 여세요. 주소가 `https://`인지 확인. 「링크 복사해서 다른 브라우저에서 열기」를 쓰세요 |
| 상대가 안 보이거나 안 들려요 | 내 마이크·카메라 버튼 상태 확인 → 컴퓨터/휴대폰 소리 크기 확인 → 다른 네트워크(Wi-Fi↔휴대폰 데이터)로 시도. 소리·영상이 멈춘 상대가 있으면 「탭하여 재생」 버튼이 나옵니다. 누르세요 |
| 「네트워크가 불안정합니다」 | **카메라를 끄면** 좋아질 수 있어요. 인원이 많을수록 화질이 자동으로 낮아집니다 |
| 「방이 가득 찼습니다」 | 한 방에 최대 6명입니다. 호스트에게 문의하거나 잠시 뒤 「다시 시도」 |
| 「방이 잠겨 있습니다」 | 호스트에게 **잠금 해제**를 요청하세요 |
| 「비밀번호가 맞지 않습니다」 | 호스트에게 비밀번호를 다시 확인하세요. 대소문자를 구분합니다 |
| 「비밀번호를 여러 번 틀려 잠시 입장할 수 없습니다」 | **10분 뒤에** 다시 시도하세요(같은 네트워크·같은 방 기준) |
| 「비밀번호는 4~32자여야 합니다」 | 호스트에게 받은 비밀번호를 그대로 다시 입력 |
| 「닉네임은 1~20자이고…」 | 허용된 글자(한글·영문·숫자·공백·`_ - .`)와 길이로 고치세요 |
| 「요청이 너무 많습니다」 | 잠시 기다렸다가 다시 시도 |
| 「지금 서버가 붐비거나 이 네트워크에서 연결이 너무 많습니다」 | 잠시 뒤 다시. 계속되면 다른 네트워크(예: 휴대폰 데이터)에서 시도 |
| 「서버와 통신하지 못했습니다」 | 인터넷 연결 확인 후 「다시 시도」 |
| 「회의를 찾을 수 없습니다」 | 이미 끝났거나 링크가 잘못됐습니다. 링크를 다시 확인하거나 새 회의를 만드세요 |
| 「호스트를 기다리고 있습니다」 | 호스트가 들어올 때까지 이 화면을 닫지 말고 기다리세요 |
| 「회의에서 내보내졌습니다」 | 호스트가 내보냈거나 §9의 차단 한계 때문일 수 있습니다. 호스트에게 문의하세요 |
| 카카오톡 등에서 링크를 열면 안 돼요 | 링크를 복사해서 Chrome/Safari 같은 일반 브라우저에서 여세요 |
| 소리가 울려요(하울링) | 같은 방에 있는 기기는 하나만 마이크·스피커를 켜거나 이어폰을 쓰세요 |
| 화면이 너무 작거나 잘려요 | 가로 360px 이상 화면을 지원합니다. 확대/축소 상태를 원래대로 |
| 그래도 해결이 안 돼요 | 화면 아래 **「문의·신고」**의 연락처로 알려 주세요(회의 링크, 문제가 생긴 시각, 어떤 문제인지). **방 비밀번호는 보내지 마세요** |

## 12. 접근성 (키보드·화면 읽기 프로그램)
- **키보드만으로** 입장부터 나가기까지 할 수 있습니다(자동 시험으로 확인). **Tab**/**Shift+Tab**으로 이동, **Enter**/**Space**로 버튼 누르기, **Esc**로 채팅·참가자 창과 확인 창 닫기. 확인 창이나 장치 설정 창이 열려 있으면 Tab 이동이 그 창 안에서만 돕니다.
- 버튼마다 이름이 붙어 있습니다(예: 「마이크 끄기」, 「마이크 켜기」). 마이크·카메라 상태는 눌림 상태로 전달되고, 입장·퇴장·오류 알림은 읽어 주는 영역으로 나옵니다. 채팅 메시지 목록도 새 글을 읽어 줍니다.
- 색만으로 상태를 구분하지 않고 아이콘과 글자를 함께 씁니다. 글자와 배경의 색 대비는 접근성 기준(AA)으로 계산해 시험했습니다. 운영체제의 「동작 줄이기」 설정을 따릅니다.
- 휴대폰에서는 버튼이 손가락으로 누르기 쉬운 크기(44px 이상)입니다. 컴퓨터 화면의 장치 선택(︿) 버튼만 작게 되어 있어요.
- **한계(미검증)**: VoiceOver·TalkBack·NVDA 같은 **실제 화면 읽기 프로그램으로는 아직 시험하지 못했습니다.** 자동 검사 기준으로만 확인했습니다. 불편하면 「문의·신고」로 알려 주세요.

## 14. 개인정보와 안전
- 영상·소리·채팅은 서버에 저장하지 않습니다. 영상은 참가자끼리 직접 전달되며(직접이 안 되면 중계 서버가 암호화된 데이터만 전달), **채팅은 종단간 암호화가 아닙니다**(서버를 거쳐 전달만 하고 저장하지 않습니다).
- 연결 과정에서 **다른 참가자와 연결 도우미 서버에 내 IP 주소 등이 보일 수 있습니다**(화상 통화 기술의 특성).
- 닉네임과 마지막 닉네임은 이 기기 브라우저에 저장되고(지울 수 있음), 호스트 정보는 방을 만든 탭에만 임시로 있습니다.
- **녹화 기능은 없습니다.** 직접 녹화하려면 법령과 상대방 동의를 지켜야 합니다.
- 개인정보 처리방침·이용약관은 화면 아래 링크에 있으며 **아직 법률 검토 전의 초안**입니다.
- 괴롭힘·불법·유해 행위를 보면 호스트에게 **내보내기·방 잠그기**를 요청하거나, 「나가기」로 바로 나올 수 있고, 「문의·신고」로 알려 주세요. 운영자는 필요하면 해당 회의를 종료할 수 있지만 모든 신고에 개별 회신을 약속하지는 않습니다.
