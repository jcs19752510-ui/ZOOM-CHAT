## 1. 정보구조(사이트맵)
URL은 두 개뿐이다. `/r/:roomId`는 방의 진행 상태에 따라 대기실, 회의실, 상태 화면을 보여 준다.

```mermaid
flowchart TD
    ROOT["/ 랜딩 SCR-01"] --> LOBBY["/r/:roomId"]
    LOBBY --> S22["호스트 대기 SCR-22"]
    LOBBY --> S02["대기실 SCR-02"]
    S02 --> S03["회의실 SCR-03"]
    S03 --> S04["채팅 패널 SCR-04"]
    S03 --> S05["참가자 패널 SCR-05"]
    S03 --> S06["장치 설정 SCR-06"]
    S03 --> S07["확인 모달 SCR-07"]
    LOBBY --> ST["상태 화면 SCR-11 ~ SCR-21"]
```

## 2. 핵심 플로우

### FLOW-01 방 생성과 공유 (P1)
```mermaid
flowchart TD
    A["랜딩 SCR-01"] --> B["닉네임 입력, 비밀번호 선택"]
    B --> C{"닉네임 규칙 통과?"}
    C -->|아니오| B
    C -->|예| D["방 만들기 요청"]
    D --> E{"서버 응답"}
    E -->|"한도 초과 또는 오류"| ERR["SCR-13 일반 오류"]
    E -->|성공| F["대기실 SCR-02 + 링크 표시"]
    F --> G["링크 복사 FR-02"]
    G --> H["입장 FLOW-02의 호스트 경로"]
```
- 요구: FR-01, FR-02, POL-04, POL-15

### FLOW-02 링크 입장 (P2, 성공 기준 경로)
```mermaid
flowchart TD
    L["링크 클릭 /r/:roomId"] --> SUP{"지원 환경?"}
    SUP -->|아니오| S20["SCR-20 지원 불가"]
    SUP -->|예| CK{"방 상태 확인"}
    CK -->|"없음 또는 만료"| S19["SCR-19"]
    CK -->|"호스트 미입장"| S22["SCR-22 호스트 대기"]
    S22 -->|"호스트 입장 시 자동"| LOBBY
    CK -->|"정상"| LOBBY["대기실 SCR-02"]
    LOBBY --> OP1["조작 1: 닉네임 입력"]
    OP1 --> OP2["조작 2: 카메라 마이크 권한 허용"]
    OP2 --> OP3["조작 3: 입장 버튼"]
    OP3 --> JR{"입장 요청 결과"}
    JR -->|"방 가득 참"| S15["SCR-15"]
    JR -->|"방 잠김"| S16["SCR-16"]
    JR -->|"강퇴 이력"| S18["SCR-18"]
    JR -->|"비밀번호 필요 또는 오류"| PW["비밀번호 입력 POL-11"]
    PW --> JR
    JR -->|성공| ROOM["회의실 SCR-03"]
```
- 비밀번호 방은 조작이 1회 늘어 4회(NFR-01). 권한 거부는 FLOW-06.
- 요구: FR-03, FR-04, FR-05, FR-06, FR-23, NFR-01, POL-01, POL-03, POL-11, POL-13

### FLOW-04 호스트 이탈과 승계
```mermaid

    B -->|아니오| C["유예 시간 동안 승계 보류"]
    C --> R{"유예 내 복귀?"}
    R -->|예| K["호스트 유지"]
    R -->|아니오| D["접속 중 참가자 중 입장 순번 최소가 새 호스트"]
```

### FLOW-07 방 상태 전이
```mermaid
stateDiagram-v2
    [*] --> 호스트대기: 방 생성
    호스트대기 --> 진행중: 호스트 입장
    호스트대기 --> 삭제됨: 생성 후 10분 무입장
    진행중 --> 진행중: 참가자 입퇴장 호스트 승계 잠금 변경
    진행중 --> 삭제됨: 마지막 참가자 퇴장 유예 종료 후
    삭제됨 --> [*]
```
- 잠금은 진행중 상태 안의 속성이다(`locked`). 잠금 중에도 유예 내 재접속은 허용한다.
- 요구: FR-18, FR-14, FR-23, POL-02, POL-03, POL-13
