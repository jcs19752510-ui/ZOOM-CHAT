## 상태
승인(구현됨)

## 배경
비용 최소와 1인 운영을 위해 배포 단위를 줄이고, 같은 Origin으로 CORS 복잡도를 없앤다.

## 결정
`WEB_DIST`가 설정되면 Express가 웹 빌드와 SPA 경로(`/r/:id`)를 제공한다. 개발 중에는 Vite가 `/api`, `/socket.io`를 서버로 프록시한다. 서버는 esbuild로 번들한다.

## 결과·트레이드오프
- 장점: 컨테이너 1개, 같은 Origin.
- 단점: 웹만 따로 CDN에 올리려면 추가 설정이 필요(후보). CSP·Origin 허용 목록을 같은 설정에서 관리.
