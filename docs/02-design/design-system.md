## 4. 반응형 규칙
| 항목 | 규칙 |
|---|---|
| 브레이크포인트 | `sm` 640px(컨트롤바 라벨·칩 표시 방식), `md` 768px(패널을 우측 열 ↔ 오버레이) |
| 갤러리 열 수 | 데스크톱: 1명=1열, 2~4명=2열, 5~6명=3열. 모바일(<640px): 1~2명=1열, 3~6명=2열. 마지막 줄이 덜 차면 가운데로 모은다 |
| 화면공유 | 데스크톱: 공유 화면 크게 + 오른쪽 썸네일 열. 모바일: 위 큰 화면 + 아래 썸네일 줄(모바일은 공유 시작 불가, 수신만) |
| 컨트롤바 | 모바일: 라벨 10px, 칩(장치 메뉴)은 숨기고 상단 설정 버튼으로 이동. 데스크톱: 마이크·카메라 옆 칩 |
| 가로 모드·키보드 | 높이는 `h-dvh`, 하단 안전 영역(`env(safe-area-inset-bottom)`) 반영. 360px에서 가로 스크롤 0(IT-10) |
