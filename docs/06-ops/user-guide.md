## 1. 회의 시작하기 (호스트)
1. 첫 화면에서 **닉네임**을 입력하고 **새 회의 만들기**를 누릅니다. (필요하면 방 비밀번호를 설정하세요.)
2. **입장 전 확인** 화면에서 카메라와 마이크가 잘 나오는지 보고 **회의 입장**을 누릅니다.
3. **초대 링크 복사**를 눌러 참가자에게 보내세요. 비밀번호를 설정했다면 비밀번호는 따로 알려 주세요(링크에는 들어가지 않습니다).

## 2. 회의 참여하기 (참가자)
1. 받은 링크를 누릅니다. 설치나 가입은 필요 없습니다.
2. 닉네임을 입력하고, 카메라·마이크 사용을 **허용**한 뒤 **회의 입장**을 누르세요.
3. 호스트가 아직 입장하지 않았다면 "호스트를 기다리고 있습니다" 화면이 나오고, 호스트가 들어오면 자동으로 진행됩니다.

## 3. 회의 중 사용법
| 하고 싶은 것 | 방법 |
|---|---|
| 마이크 / 카메라 끄고 켜기 | 아래 **마이크**, **카메라** 버튼 |
| 장치 바꾸기 | 마이크·카메라 옆 ︿ 버튼(휴대폰은 위쪽 톱니바퀴) |
| 화면 공유 | **화면공유** 버튼(컴퓨터 브라우저만, 한 번에 한 명) |
| 채팅 | **채팅** 버튼. 대화는 서버에 저장되지 않고 회의가 끝나면 사라집니다 |
| 참가자 보기 | **참가자** 버튼 |
| 나가기 | 빨간 **나가기** 버튼. 같은 링크로 다시 들어올 수 있습니다 |

## 4. 호스트 기능
참가자 목록에서: **방 잠그기**(새 사람 입장 막기), **전체 음소거**(모두 마이크 끄기, 각자 다시 켤 수 있음), **내보내기**(내보낸 사람은 다시 들어올 수 없습니다). 호스트가 나가면 가장 먼저 들어온 참가자가 호스트가 됩니다.

## 5. 지원 환경
Chrome, Edge, Firefox, Safari 최신 버전과 아이폰 Safari를 지원합니다. 휴대폰 브라우저에서는 **화면 공유를 쓸 수 없습니다**. 보안 연결(주소가 https)에서만 카메라가 동작합니다.

## 6. 문제 해결 (FAQ)
| 문제 | 해결 |
|---|---|
| "카메라 권한이 차단되었습니다" | 주소창 왼쪽 **자물쇠 아이콘** → 카메라·마이크 **허용** → 페이지 새로고침. 장치 없이도 입장해서 보고 들을 수는 있습니다 |
| "다른 앱이 카메라를 사용 중" | 화상회의·카메라 앱을 닫고 **다시 확인**을 누르세요 |
| 상대가 안 보이거나 안 들려요 | 내 마이크·카메라 버튼 상태 확인 → 휴대폰은 소리 크기 확인 → 다른 네트워크(Wi-Fi↔LTE)로 시도 |
| "네트워크가 불안정합니다" | 카메라를 끄면 나아질 수 있습니다. 인원이 많을수록 화질을 자동으로 낮춥니다 |
| "재연결 중" | 잠시 기다리세요. 20초 안에 돌아오면 같은 자리에서 계속됩니다. 오래 끊기면 다시 입장하세요 |
| "방이 가득 찼습니다" | 한 방에 최대 6명입니다. 호스트에게 문의하세요 |
| "방이 잠겨 있습니다" | 호스트에게 잠금 해제를 요청하세요 |
| "회의를 찾을 수 없습니다" | 이미 끝났거나 링크가 잘못되었습니다. 링크를 다시 확인하거나 새 회의를 만드세요 |
| "서비스가 재시작되어 회의가 종료되었습니다" | 서비스를 점검하는 중이었습니다. 새 회의를 만들어 다시 시작하세요 |
| 카카오톡 등에서 링크를 열면 안 돼요 | 링크를 복사해서 Chrome/Safari 등 일반 브라우저에서 여세요 |

## 7. 개인정보
영상·음성·채팅은 서버에 저장하지 않습니다. 영상 통화 연결 과정에서 다른 참가자에게 내 네트워크 정보(IP 등)가 보일 수 있습니다.
