## 3. 핵심 결정 5개
1. **호스트 입장 전에는 참가자가 방에 들어가지 않는다(대기 화면, FR-23/POL-13)**: 링크가 먼저 새도 생성자가 아닌 사람이 호스트가 되지 않게 한다. (A-03, 승인 필요)
2. **재접속 유예 20초 동안 자리와 호스트 승계를 보류한다(POL-05/08, NFR-03)**: 짧은 끊김에 호스트가 바뀌는 혼란을 막는다. 유예 중인 참가자도 정원에 포함한다. (A-02, 승인 필요)
3. **강퇴 차단은 세션 + IP 해시, 서버 메모리에만, 방 삭제 시 소멸(POL-06)**: 계정이 없어서 필요한 최소 수단이며 우회 가능하다는 한계를 문서에 명시한다. (A-05, 승인 필요)
4. **화면공유는 방당 동시 1명, 먼저 시작한 사람 우선(POL-12)**: "공유 화면을 크게" 레이아웃(UX-06)이 성립하는 가장 단순한 규칙. (A-04, 승인 필요)
5. **"입장 3번 이내 조작"을 측정 가능하게 정의(NFR-01, 용어집)**: 닉네임 입력, 권한 허용, [입장] 각 1회. 링크 클릭은 세지 않으며 비밀번호 방은 4회까지. KPI-02, FLOW-02, SCR-02가 같은 정의를 쓴다.
