## 1. 공통 규칙 (모든 화면에 적용)
- 한국어, 문구는 strings 키로만 참조(UX-01). 다크 테마 기본·토큰만 사용(UX-08). 360px부터 반응형·터치 44px 이상(NFR-10). 키보드 조작·aria-label·포커스 표시(UX-10, NFR-09). reduced-motion 존중(UX-11). 오류는 원인+해결 방법(UX-03). 알림은 토스트(UX-12).
- 문구 키 형식: `<화면>.<요소>` (예: `lobby.joinButton`). 실제 문구는 0-B `content-guide.md`에 둔다.
- 라우트: `/` 랜딩, `/r/:roomId` 대기실과 회의실(방 ID는 URL 경로, 비밀번호는 URL에 넣지 않음. A-10).

## 3. 주 화면

### SCR-01 랜딩
- **목적**: 새 방을 만들거나 받은 링크·코드로 입장한다.
- **진입 → 이탈**: 사이트 접속 → [방 만들기] 성공 시 SCR-02 / 링크·코드 입력 후 [입장] 시 SCR-02.
- **구성**: 서비스명(텍스트 로고), 닉네임 입력, 선택 비밀번호 입력(접힘), [방 만들기], 링크/코드 입력과 [입장], 지원 환경 한 줄 안내, 개인정보 처리 한 줄 링크(0-D).
- **상태·동작**: 닉네임 규칙 위반은 입력 아래에 즉시 사유 안내(POL-04). 생성 요청 중 [방 만들기]는 로딩 상태로 중복 제출을 막는다. 서버 오류는 SCR-13. 지원 불가 브라우저는 SCR-20.
- **요구**: FR-01, FR-03, FR-06, UX-01, UX-03, POL-04, POL-11
- **문구 키**: `landing.title`, `landing.nickname*`, `landing.createButton`, `landing.joinByLink*`, `landing.password*`

### SCR-02 대기실
- **목적**: 입장 전에 카메라·마이크를 확인하고 닉네임(필요 시 비밀번호)을 입력해 입장한다.
- **진입 → 이탈**: 방 생성 직후 또는 링크 접속 → [입장] 시 SCR-03. 거부 사유에 따라 SCR-15/16/18/19/22. [취소]는 SCR-01.
- **구성**: 카메라 미리보기, 마이크 레벨 미터, 장치 선택(카메라/마이크/스피커 지원 시), 마이크·카메라 켜짐 상태 토글, 닉네임 입력(링크 입장 시), 비밀번호 입력(비밀번호 방일 때), [링크 복사], 개인정보(IP) 고지(UX-09), [입장].
- **상태·동작**: ① 권한 요청 중은 로딩 표시. ② 권한 허용 시 미리보기와 레벨 미터 표시. ③ 권한 차단 시 SCR-14 내용을 인라인으로 표시하고, "장치 없이 입장"을 허용한다. ④ 장치 없음/사용 중이면 원인 안내. ⑤ 비밀번호 오류는 입력 아래에 남은 시도 가능 여부를 안내(POL-11). 조작은 닉네임 입력, 권한 허용, [입장] 3회로 완료 가능해야 한다(NFR-01).
- **요구**: FR-02, FR-03, FR-04, FR-05, NFR-01, UX-03, UX-09, POL-04, POL-11, POL-16
- **문구 키**: `lobby.preview*`, `lobby.device*`, `lobby.privacyNotice`, `lobby.joinButton`, `lobby.copyLink`

### SCR-03 회의실
- **목적**: 참가자와 통화하고 호스트/참가자 기능을 사용한다.
- **진입 → 이탈**: SCR-02 [입장] 성공 → [나가기] 확인 시 SCR-21. 강퇴 시 SCR-18, 연결 문제 시 SCR-17, 방 소멸 시 SCR-19.
- **구성**: 비디오 그리드(1~6명 자동 배치, UX-05), 각 타일(이름, 마이크/카메라 상태, 호스트 표시, 발언자 강조), 화면공유 레이아웃(공유 화면 크게+썸네일, UX-06), 연결 상태 배지(FR-19), 하단 컨트롤바(마이크, 카메라, 화면공유, 채팅, 참가자, 나가기. 나가기는 분리·위험색, UX-04), 사이드 패널 영역(SCR-04/05), 링크 복사.
- **상태·동작**: 마이크/카메라 토글(FR-08), 화면공유 시작/중지(FR-12), 호스트 변경·입퇴장·전체 음소거는 토스트(UX-12), 모바일에서는 패널이 바텀시트로 열리고 화면공유 버튼은 비활성+안내. 혼자 있을 때는 SCR-12.
- **요구**: FR-02, FR-07, FR-08, FR-10, FR-12, FR-19, FR-22, UX-04, UX-05, UX-06, UX-07, UX-12, NFR-13, POL-12
- **문구 키**: `room.control*`, `room.tile*`, `room.status*`, `room.toast*`

### SCR-04 채팅 패널
- **목적**: 방 안 텍스트 대화.
- **진입 → 이탈**: 컨트롤바 [채팅] 토글 / 닫기.
- **구성**: 메시지 목록(보낸 사람, 시간, 텍스트), 입력창(500자 카운터), [전송], 읽지 않은 메시지 표시.
- **상태·동작**: 메시지 없음은 SCR-12 빈 상태. 500자 초과·속도 제한은 전송 전 안내. 링크는 새 탭으로 열리는 텍스트 링크. 새 메시지는 스크린리더에 전달한다. 입장 이전 대화는 없다.
- **요구**: FR-11, UX-12, POL-07
- **문구 키**: `chat.*`

### SCR-05 참가자 패널
- **목적**: 참가자 상태 확인, 호스트 도구 사용.
- **진입 → 이탈**: 컨트롤바 [참가자] 토글 / 닫기.
- **구성**: 참가자 목록(이름, 호스트 표시, 마이크/카메라/공유 상태), 호스트에게만 [방 잠금/해제], [전체 음소거], 각 참가자 [강제 퇴장].
- **상태·동작**: 목록은 입퇴장·상태 변경 시 즉시 갱신. 호스트 도구 표시는 보조이며 서버가 권한을 판단한다. 강퇴·전체 음소거는 SCR-07 확인 후 실행. 잠금 상태를 표시한다.
- **요구**: FR-13, FR-14, FR-15, FR-16, FR-17, POL-03, POL-05
- **문구 키**: `participants.*`, `host.*`

### SCR-06 장치 설정 시트
- **목적**: 통화 중 카메라·마이크·(지원 시) 스피커를 바꾼다.
- **진입 → 이탈**: 컨트롤바의 장치 메뉴 / 닫기.
- **구성**: 장치 선택 목록, 현재 선택 표시, 마이크 레벨 미터.
- **상태·동작**: 장치 변경 중 통화는 유지된다. 장치가 하나뿐이면 목록을 비활성 표시한다. 권한 문제는 SCR-14로 안내한다.
- **요구**: FR-09, FR-04
- **문구 키**: `devices.*`

### SCR-07 확인 모달
- **목적**: 되돌리기 어려운 동작 전 확인(나가기, 강제 퇴장, 전체 음소거).
- **구성**: 제목, 영향 설명, [취소]와 [확인](위험 동작은 위험색). 기본 포커스는 [취소].
- **상태·동작**: Esc로 취소, 포커스는 모달 안에 가둔다.
- **요구**: FR-15, FR-16, FR-22, UX-10
- **문구 키**: `confirm.*`

## 4. 상태 화면
각 상태 화면은 **원인, 해결 방법, 다음 행동 버튼**을 갖는다(UX-03).

### SCR-11 로딩
- **언제**: 방 정보 확인 중, 권한 요청 중, 입장 처리 중, 미디어 연결 중.
- **구성**: 진행 표시와 현재 단계 문구. 지연 임계값을 넘으면(0-B에서 확정) "연결이 오래 걸리고 있습니다" 안내와 [다시 시도].
- **요구**: UX-02, NFR-02
- **문구 키**: `state.loading.*`

### SCR-12 빈 상태
- **언제**: 회의실에 나 혼자 있을 때, 채팅 메시지가 없을 때.
- **구성**: "아직 아무도 없어요" 안내와 [링크 복사]. 채팅은 "첫 메시지를 보내 보세요".
- **요구**: UX-02, FR-02
- **문구 키**: `state.empty.*`

### SCR-13 일반 오류
- **언제**: 서버 오류, 예상 못 한 오류, 요청 한도 초과.
- **구성**: 원인(내부 정보 없이), 해결 방법, [다시 시도], [처음으로].
- **요구**: UX-02, UX-03, SEC-08, POL-10, POL-15
- **문구 키**: `state.error.*`

### SCR-14 권한 거부
- **언제**: 카메라/마이크 권한 차단, 장치 없음, 장치가 다른 앱에서 사용 중.
- **구성**: 예 "카메라 권한이 차단되었습니다. 주소창의 자물쇠 아이콘에서 허용한 뒤 새로고침해 주세요." 브라우저별 안내, [다시 확인], [장치 없이 입장].
- **요구**: FR-04, UX-02, UX-03
- **문구 키**: `state.permission.*`

### SCR-15 방 가득 참
- **언제**: 정원 초과 입장 시도.
- **구성**: 원인(정원 N명), 해결 방법(호스트에게 문의, 잠시 후 재시도), [다시 시도], [처음으로].
- **요구**: FR-06, POL-01
- **문구 키**: `state.full.*`

### SCR-16 방 잠김
- **언제**: 잠긴 방에 신규 입장 시도.
- **구성**: 원인(호스트가 방을 잠금), 해결 방법(호스트에게 잠금 해제 요청), [다시 시도].
- **요구**: FR-06, FR-14, POL-03
- **문구 키**: `state.locked.*`

### SCR-17 연결 끊김·재연결
- **언제**: 소켓/네트워크 단절, 불안정, 재연결 중.
- **구성**: 상단 상태 배지와 배너("재연결 중... 남은 시간"), 불안정 시 "카메라를 끄면 개선될 수 있습니다", 유예 초과 시 [다시 입장].
- **상태·동작**: 색만이 아닌 아이콘+문구로 표시. 복구되면 토스트로 알린다.
- **요구**: FR-19, FR-20, POL-08, UX-12
- **문구 키**: `state.connection.*`

### SCR-18 강퇴됨
- **언제**: 호스트가 강제 퇴장시킴. 같은 링크로 재입장 시도 시에도 이 화면.
- **구성**: 원인(호스트의 조치), 해결 방법(호스트에게 문의), [처음으로].
- **요구**: FR-15, FR-06, POL-06
- **문구 키**: `state.kicked.*`

### SCR-19 방 없음·만료·서비스 재시작
- **언제**: 삭제·만료된 방, 잘못된 링크, 서버 재시작.
- **구성**: 원인별 문구(이미 종료됨/링크 확인/서비스 재시작), [새 방 만들기], [처음으로].
- **요구**: FR-06, FR-18, FR-21, POL-02, POL-08
- **문구 키**: `state.gone.*`

### SCR-20 지원 불가 환경
- **언제**: WebRTC/미디어 API 미지원 브라우저, 비보안(HTTP) 컨텍스트.
- **구성**: 원인, 권장 브라우저 안내, 링크 복사로 다른 브라우저에서 열기.
- **요구**: NFR-05, POL-14, FR-06
- **문구 키**: `state.unsupported.*`

### SCR-21 퇴장 완료
- **언제**: [나가기] 확인 후, 또는 유예 초과로 퇴장됐을 때.
- **구성**: "회의에서 나왔습니다", [다시 입장](방이 남아 있을 때만 성공), [처음으로].
- **요구**: FR-22, POL-08
- **문구 키**: `state.left.*`

### SCR-22 호스트 대기
- **언제**: 방 생성자(호스트)가 입장하기 전에 참가자가 접속했을 때(A-03).
- **구성**: "호스트가 입장하면 자동으로 시작됩니다", 취소 버튼. 호스트가 입장하면 SCR-02로 자동 진행.
- **요구**: FR-23, POL-13
- **문구 키**: `state.waitHost.*`
