## 상태
승인(구현됨)

## 배경
HTTP 롱폴링은 Origin 헤더가 없는 동일 출처 요청이 있어 Origin 허용 목록 검사가 약해지고, 지연이 늘어난다.

## 결정
Socket.IO `transports: ["websocket"]`만 허용하고, 모든 연결에서 Origin을 허용 목록과 대조한다(없으면 거부).

## 결과·트레이드오프
- 장점: Origin 검사 일관, 지연 감소.
- 단점: WebSocket을 막는 프록시 환경에서는 연결 불가(드묾). 인증 프록시 환경은 UAT-04에서 확인.
