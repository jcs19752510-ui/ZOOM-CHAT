## 1. 서비스/기능 개요 및 목적

- **서비스**: MeetLite(가칭). 설치·로그인 없이 브라우저 링크로 입장하는 한국어 웹 화상회의. 방당 최대 6명(설정값, WebRTC mesh), 서버 1대(앱+coturn), 1인 운영, 비용 최소.
- **목적**: 비전문가 개인·소규모 모임이 앱 설치·가입 없이 링크 하나로 바로 만나게 한다.
- **성공 기준(CLAUDE.md)**: 링크 클릭 후 3번 이내의 조작으로 입장해 서로 영상이 보인다(NFR-01, KPI-02).
- **현황(사실)**: Gate 0-A~0-E, Phase 1~5 구현·검증 완료, Phase 6은 자동 검증분 완료(UAT·타 브라우저·법률·실서버 미검증), Phase 7 문서 완료. 미배포(규칙 E).
- **이 기획서의 새 역할**: 1단계 시사점 5개 중 기존 요구로 덮이지 않은 부분(개인정보 고지·보유, 신고·수사협조, 연령·약관, 법률·라이선스 게이트, 인앱·iOS UX, mesh/TURN 수치·coturn 검증)을 신규 요구로 등록해 3단계 이후 단계가 누락하지 않게 한다.
